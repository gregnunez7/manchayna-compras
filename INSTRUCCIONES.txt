MANCHAYNA COMPRAS 2.4 PWA

1. Haz copia de seguridad de tu proyecto.
2. Copia todos los archivos de este ZIP a la RAÍZ de tu repositorio GitHub.
3. CONSERVA tu supabase-config.js actual: no está incluido.
4. Sube también la carpeta icons con sus dos imágenes.
5. GitHub Pages publicará los cambios. Abre la URL y comprueba que funciona el login.
6. En iPhone: Safari > Compartir > Añadir a pantalla de inicio. Si ya existía un acceso directo, puedes quitarlo y volverlo a añadir para ver el icono nuevo.

La interfaz puede cargar algunos archivos desde caché, pero los datos de Supabase y el OCR siguen necesitando Internet. No uses la app para comprar sin conexión.
No se incluyen contraseñas ni claves secretas.
